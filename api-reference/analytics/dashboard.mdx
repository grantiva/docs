---
title: "Dashboard"
description: "Get analytics dashboard data"
---

## Request

```
GET /api/v1/analytics/dashboard
```

### Headers

| Header | Required | Description |
|--------|----------|-------------|
| `X-API-Key` | Yes | Your API key |

### Query parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `timeRange` | `string` | `30d` | `1d`, `7d`, `30d`, or `90d` |
