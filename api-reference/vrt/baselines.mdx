## Authentication

All VRT endpoints take an API key, sent as `X-API-Key` or `Authorization: Bearer <key>`. Reads require the `vrt:read` scope, writes require `vrt:write`.

Baselines are stored per project, branch, and screen name. Uploading a baseline creates the project on first use; the read and delete routes return `404` for a project slug that does not exist in your organization.

---

## List baselines

```
GET /api/v1/vrt/baselines/:project/:branch
```

### Response

```json
{
  "screens": ["Home", "Login", "Profile", "Settings"]
}
```

Screen names, sorted alphabetically. An empty array means the branch has no baselines yet.

---

## Download baseline

```
GET /api/v1/vrt/baselines/:project/:branch/:screen
```

Returns PNG image data (`Content-Type: image/png`), or `404` when no baseline exists for that screen.

---

## Upload baseline

```
POST /api/v1/vrt/baselines/:project/:branch/:screen
```

Upload a PNG image as the new baseline for a screen. Replaces the existing baseline if there is one.

### Body

Raw binary PNG data — not multipart.

### Response

`200 OK` with an empty body. An empty request body returns `400`.

---

## Delete baseline

```
DELETE /api/v1/vrt/baselines/:project/:branch/:screen
```

### Response

`204 No Content`

---

## Promote baselines

Copy every baseline from one branch to another — typically promoting a feature branch's approved baselines onto `main`. Existing baselines on the target branch are overwritten; baselines the source branch does not have are left alone.

```
POST /api/v1/vrt/baselines/:project/:branch/promote
```

`:branch` is the **target** branch.

### Body

```json
{
  "from_branch": "feature/new-ui"
}
```

### Response

`200 OK`. Returns `404` when the source branch has no baselines.

## GitHub app link

Links a project to a GitHub App installation so VRT results can be reported on pull requests.

```
POST /api/v1/vrt/github/install
```

```json
{
  "installation_id": 12345678,
  "account_login": "acme",
  "project": "checkout-app"
}
```

Creates the project if it does not exist, and replaces any existing link for it.

**Response** — `200 OK`

```json
{
  "status": "linked",
  "installation_id": 12345678,
  "project": "checkout-app"
}
```

```
GET /api/v1/vrt/github/install/:project
```

**Response** — `200 OK`

```json
{
  "installed": true,
  "installation_id": 12345678,
  "account_login": "acme"
}
```

An unknown project or an unlinked one returns `200` with `"installed": false` and null fields.
